# 数字时代广场：愿景与定位

## 1. 我们在解决什么

AI 正在重写工作、品牌和产品的坐标系，但公共信息仍是碎片：

| 用户问题 | 现状 | 广场回答 |
|---------|------|---------|
| 该关注谁？ | 热搜、饭圈、不可复核的「影响力」 | **AI 名人榜**：人被锚定到行业、场景、能力 |
| 该信任哪家公司？ | 融资新闻、PR 稿、封闭研报 | **AI 品牌榜**：品牌被拆成产品、场景覆盖、资产厚度 |
| 该用什么产品？ | 工具导航站、评测号、口碑群 | **AI 产品榜**：产品被映射到场景 KPI 与角色工作流 |
| 我所在的行业怎么被 AI 改写？ | 咨询 PPT、个案文章 | **行业资产库**：可版本化的场景 / 流程 / 角色 / Agent / 能力 |
| Agent 和团队该接哪些工具？ | Awesome 列表、厂商文档 | **AI 工具库**：带接口、约束、场景适用性的可调用目录 |

现有 world-professors 已经开始回答后两问（资产与工具），但缺少**公共注意力入口**。没有「谁」和「什么」被看见，标准库很难成为产业习惯。

广场补上前三问，并把五者绑在同一套产业坐标上。

## 2. 产品隐喻：广场，而不是目录

**时代广场 / 雅典agora** 同时具备：

- **注意力**：大屏、排行、被看见（三榜）
- **市集**：可交易、可调用的资产与工具（两库）
- **身份**：人与组织在公共空间里被识别（认领、认证）
- **议事**：标准如何被讨论、修订、引用（维基 + 专家审核）

因此产品不是「又一个榜单媒体」，也不是「又一个工具导航」，而是：

> **AI 时代的公共广场 = 注意力交易所 + 专业资产交易所**  
> 三榜是大屏，两库是档案与市集，world-professors 是地上的坐标网格。

## 3. 五馆定义

### 3.1 AI 名人榜（Who）

收录在 AI 时代形成公共影响力、专业贡献或场景实践力的**人与数字人格**：

- 研究者 / 科学家
- 创始人与企业经营者
- 产品与工程构建者
- 行业实践者（按场景，而非按粉丝）
- 教育者与开源贡献者
- 新兴：**数字分身 / AI Persona**（明确标注为非自然人）

**广场差异**：不只比声量。每个人绑定 `industry / scenario / capability / role`，区分「出圈影响力」与「专业贡献力」两套榜。

### 3.2 AI 品牌榜（Who owns）

收录以 AI 为核心能力或核心叙事的组织：

- 基础模型实验室
- 应用层公司
- 云与基础设施
- 垂直行业 AI 品牌
- 开源组织与联盟
- 区域品牌（中国 / 全球分榜，避免虚假全球第一）

**广场差异**：品牌分值来自「产品组合 × 场景覆盖 × 资产厚度 × 工具被调用」，而不是估值或公关预算。

### 3.3 AI 产品榜（What）

收录可被使用、可被比较的 AI 产品：

- 按品类：模型、编程、图像、视频、搜索、Agent、企业套件
- 按场景：财富管理、软件研发、客服、诊疗辅助……（接 world-professors）
- 按用户：C 端 / B 端 / 开发者

**广场差异**：产品页必须回答「服务哪个场景、替代/增强哪个角色、调用哪些工具、对应哪些能力」。

### 3.4 AI 行业资产库（How / Where）——本体所在

这是 world-professors 的主场，升级为可被检索、引用、授权的**产业资产**：

| 资产类型 | 对应现有模型 | 广场中的意义 |
|---------|-------------|-------------|
| 行业 | Industry | 广场分区 |
| 场景 | Scenario | 榜单与产品的主索引 |
| 价值流 / 流程 | Workflow | Agent 与工具的编排坐标 |
| 角色 | Role | 人与职业转型入口 |
| Agent | Agent | 机器可消费的标准作业单元 |
| 能力 | Capability | 学习、招聘、认证的尺子 |
| 案例 / 模式 | Practice | 可复用的变革剧本 |
| 数据集 / 模型卡 | 新增 | 行业专用数据与模型资产 |

**资产**意味着：可版本化、可引用、可组合、未来可授权——不是长文专栏。

### 3.5 AI 工具库（With what）

在现有 Tool 模型上，升级为广场可浏览、可比较、可被 Agent 查询的目录：

- API / SDK / MCP / 插件 / GPT / Agent-as-tool
- 认证、限流、定价、供应商
- 适用行业、场景、能力、步骤
- 与产品榜的关系：产品是货架上的 SKU，工具是可被编排的接口

## 4. 目标用户（按广场角色）

### 4.1 需求侧

| 角色 | 来广场做什么 | 付费意愿 |
|------|-------------|---------|
| 知识工作者 / 转型者 | 看该关注谁、用什么、补什么能力 | 低票价会员、学习路径 |
| Agent / 应用开发者 | 查标准流程、能力边界、工具接口 | 中：API、标准库许可证 |
| 企业 L&D / HR / 数字化 | 能力框架、岗位演进、工具选型 | 高：企业订阅、诊断 |
| 投资人 / 分析师 | 品牌-产品-场景覆盖与趋势 | 高：数据与报告 |
| 媒体 / 研究者 | 可引用的方法论与结构化条目 | 中：数据授权 |

### 4.2 供给侧

| 角色 | 来广场做什么 | 付费意愿 |
|------|-------------|---------|
| 名人 / 专家 | 认领主页、展示能力与作品 | 中：认证、主页增值 |
| 品牌 / 产品团队 | 被正确分类、被场景检索到 | 高：入驻、认证、洞察 |
| 工具厂商 | 进入 Agent 可调用目录 | 高：上架、分发、线索 |
| 行业专家 / 贡献者 | 贡献场景与案例，积累声誉 | 激励：分成、身份 |

## 5. 竞争格局与差异

| 类型 | 代表 | 强项 | 缺口 | 广场打法 |
|------|------|------|------|---------|
| 工具导航 | There's An AI For That、未来pedia | 覆盖广、更新快 | 无产业深度、榜单无方法 | 工具必须挂场景与能力 |
| 评测目录 | G2、Capterra | 评论与采购 | 非 AI 原生、无人/无行业本体 | 场景 KPI 评测，而非星级堆砌 |
| 公司数据 | Crunchbase、IT 桔子 | 融资与图谱 | 贵、封闭、弱场景 | 品牌×产品×场景公开层免费 |
| 职业网络 | LinkedIn | 人与岗位 | 非 AI 时代坐标 | 人绑定能力等级与角色演进 |
| 模型社区 | Hugging Face | 模型/数据 | 偏开发者，弱行业经营 | 行业资产库吸收模型卡，面向场景 |
| 百科 | Wikipedia | 中立与引用 | 无榜、无交易、无 Agent 消费 | 维基精神 + 可调用 Schema |
| 财富榜 / 名人榜 | 胡润、福布斯 | 注意力 | 方法不透明、与工作无关 | 双榜：影响力 / 专业贡献 |
| 本项目现状 | world-professors | 本体清楚 | 无公共入口、无商业闭环 | 广场作为产品层 |

**不可替代点（Moat 假设）**：

1. **坐标系**：行业×场景×能力，使所有实体可互链、可比较。
2. **双消费者**：人读得懂，Agent 调得动（Schema / 约束 / 工具接口）。
3. **公信力协议**：榜单方法公开，付费永不改名次，只买「被看见的位置」（认证、精选位需标注）。

## 6. 产品原则（广场特有）

在原 product.md 五原则之上，广场增加：

1. **坐标先于热度**：没有行业/场景锚点的条目，不能进正式榜。
2. **名次不可买**：商业化只作用于展示层（认证标、精选卡），分数算法与名次隔离。
3. **人机双读**：每条正式资产同时服务页面阅读和 Agent 查询。
4. **一本账**：名人、品牌、产品、工具、资产共享 ID 与引用，禁止五套互不相认的 CMS。
5. **中文场景先用起来**：全球实体可收录，但优先做透中国产业场景（金融、科技、制造、医疗、专业服务）。

## 7. 成功时广场长什么样

一个软件工程师打开广场：

1. 在**产品榜·编程助手**看到 Cursor / Copilot 的场景对比（对应 `scn-tech-software-dev`）。
2. 点进产品，看到它增强的角色、调用的工具、所需能力。
3. 跳到**工具库**拿到接口与约束，跳到**资产库**看到标准「功能开发流程」。
4. 在**名人榜·工程实践**看到该场景下的构建者，在**品牌榜**看到背后公司的场景覆盖。

一个财富管理机构的数字化负责人打开广场：

1. 在**行业资产库·财富管理**看到标准流程与 Agent 边界。
2. 在**产品榜 / 工具库**筛「可用于客户画像、且满足合规约束」的产品。
3. 下载能力矩阵给 L&D，用 API 把 Agent 标准定义接到内部平台。

这就是升华完成的标志：**注意力、选型、标准和调用发生在同一张地图上。**
