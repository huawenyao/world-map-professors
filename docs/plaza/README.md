# 数字时代广场

> AI 时代的公共注意力与专业资产交易所  
> 三榜捕获流量与公信力，两库沉淀可复用资产，底层由 world-professors 本体作为坐标系。

**定位一句话**：面向资源需求方的产业生态工作台——**评估并链接达人与品牌**，再在场景里把合作交付完。

五馆是供给库存，不是逛馆游戏。找人 / 找企业是入口；评估是尺子；合作项目是战役；AI Man 只出现在已覆盖场景的交付里。

## 与现有项目的关系

| 层 | 名称 | 职责 |
|----|------|------|
| 产品层 | **数字时代广场** | 面向公众与产业的注意力广场、入驻与交易入口 |
| 知识层 | **world-professors** | 行业 × 场景 × 流程 × 角色/Agent × 能力 × 工具的标准本体 |
| 数据层 | YAML + Git | 单一事实源，版本可追溯，开放协作 |

**升华逻辑**：world-professors 从「给人读的维基 / 给 Agent 用的标准库」升级为广场的**产业坐标系**。名人、品牌、产品、工具不再漂在热搜上，而是被锚定到具体行业、场景、能力和工作流上。

```
                    ┌─────────────────────────────────────┐
                    │         数字时代广场 (Plaza)          │
                    │   注意力 × 身份 × 资产 × 工具          │
                    └──────────────┬──────────────────────┘
           ┌───────────┬───────────┼───────────┬───────────┐
           ▼           ▼           ▼           ▼           ▼
      AI名人榜     AI品牌榜     AI产品榜    行业资产库    AI工具库
      (Who)       (Who owns)   (What)     (How/Where)   (With what)
           └───────────┴───────────┴─────┬─────┴───────────┘
                                         ▼
                    场景解决方案服务 · AI Man（自适应交付）
                                         ▼
                    world-professors 本体（行业/场景/流程/角色/能力/Agent）
```
